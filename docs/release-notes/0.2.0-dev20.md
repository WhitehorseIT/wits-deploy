**Test build.** A pre-release for hardware testing, not a stable release.

## What's new
- **App self-update (Linux).** When a newer signed release exists, an **Update app…** button appears. It downloads and verifies the new version, installs it beside the current one, and restarts into it. If the new version fails to start, the previous one is launched instead.
- Firmware is unchanged from 0.2.0-dev18.

## Files
- `WITS-Deploy-Firmware-0.2.0-dev20.zip`: firmware for the T-QT Pro, Waveshare 7-inch and Waveshare 1.47-inch.
- `WITS-Deploy-0.2.0-dev20-Linux-x86_64.tar.gz`: the Linux desktop app. From dev19 you can update from inside the app once this is published; otherwise extract with `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev20-Linux-x86_64.tar.gz -C ~/Apps` and run `INSTALL-LAUNCHER.sh`.
- `release-manifest.json` and `.sig`: the signed manifest the app checks.
- Windows: run the app from source for now; see the README.

Not yet verified on hardware: Windows and interrupted Bluetooth updates.
