**Test build.** A pre-release for hardware testing, not a stable release.

## What's new
- **The app and the firmware now release separately.** App releases use the tag `v<version>`; firmware releases use `fw-v<version>`. The Firmware column and **Download latest firmware** follow the firmware releases, and **Update app…** follows the app releases, so an app-only release no longer makes your boards look out of date.
- The app bundles firmware 1.0.0-rc1 (see its own release).
- The startup check makes one request instead of two.
- Documentation updated, including a new compatibility guide.

## Updating
From 0.2.0-dev20 or newer the Linux app updates itself: use **Update app to 0.2.0-dev23…**. Otherwise extract the Linux archive with `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev23-Linux-x86_64.tar.gz -C ~/Apps` and run `INSTALL-LAUNCHER.sh`. Apps older than dev23 will not see firmware releases; use dev23 or newer to download firmware from inside the app.
