**Test build.** A pre-release for hardware testing, not a stable release.

## What's new
- **Safer updates over Bluetooth.** Starting an update now switches Auto-connect off on every board, connected or not, so no board reconnects mid-update, and restores it afterwards. If the other boards cannot be disconnected, the update does not start and your settings are left as they were.
- **Closing the app.** With boards connected, a notice with a countdown explains the short wait while each board releases its Bluetooth link, and the window stays responsive. With nothing connected the app closes immediately.
- The post-update message now says the board restarts in HID mode.
- Release manifests tolerate files they do not yet know about, so later releases can add downloads without breaking updates.
- Documentation rewritten for the current state.
- Firmware is unchanged apart from its version number.

## Updating
From 0.2.0-dev20 or newer the Linux app updates itself: use **Update app to 0.2.0-dev22…**. Otherwise extract the Linux archive with `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev22-Linux-x86_64.tar.gz -C ~/Apps` and run `INSTALL-LAUNCHER.sh`.

## Files
- `WITS-Deploy-Firmware-0.2.0-dev22.zip`, `WITS-Deploy-0.2.0-dev22-Linux-x86_64.tar.gz` and the signed `release-manifest.json` with its `.sig`.
- Windows: run the app from source for now; see the README.
