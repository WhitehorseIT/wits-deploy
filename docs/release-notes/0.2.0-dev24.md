**Test build.** A pre-release for hardware testing, not a stable release.

## What's new
- **Fixes a crash after a failed firmware update.** The app could crash when the update dialog closed, because a worker thread held a reference to a dialog. Dialogs are now deleted on the interface thread and worker threads no longer touch them. If the app ever crashes hard, it now writes every thread's Python stack to `crash-traces.log` next to the main log.
- **Fixes the menu opening an older version after an in-app update.** KDE launches from a cached application index; after moving the shortcuts the app now rebuilds that cache.
- **Safer rollback during updates.** The previous version is started only if the new one fails before it has confirmed itself (about 15 seconds after starting). A crash after that is never rolled back.
- The file picker for firmware manifests now reopens in the folder you last used, falling back to Downloads. It won't wait on a remembered folder that sits on a stalled network share.
- The log now records which process launched the app, and the on-screen event log is also written to the log file.
- Firmware is unchanged: the app bundles 1.0.0-rc1.

## Updating
From 0.2.0-dev20 or newer the Linux app updates itself: use **Update app to 0.2.0-dev24…**. After the update, if the menu still opens an older version, run `kbuildsycoca6 --noincremental` once. Otherwise extract the Linux archive with `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev24-Linux-x86_64.tar.gz -C ~/Apps` and run `INSTALL-LAUNCHER.sh`.
