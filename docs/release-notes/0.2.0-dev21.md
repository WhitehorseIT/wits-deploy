## What's new
- Updated the `cryptography` library to version 50 (clears four published advisories; none affected the app's use of it, which is limited to checking release signatures).
- Firmware is unchanged from 0.2.0-dev18.

## Updating
From 0.2.0-dev20 the desktop app updates itself: use **Update app to 0.2.0-dev21…**. Otherwise extract the Linux archive with `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev21-Linux-x86_64.tar.gz -C ~/Apps` and run `INSTALL-LAUNCHER.sh`.

- Windows: run the app from source for now; see the README.
