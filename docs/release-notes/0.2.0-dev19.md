**Test build.** A pre-release for hardware testing, not a stable release.

## What's new
- **Signed releases.** Each release now has a signed manifest. The app verifies it, uses it for the critical-update highlight, and can download firmware straight from the release (**OTA Update…** then **Download latest firmware**), checking every file before use.
- Firmware itself is unchanged from 0.2.0-dev18.

## Files
- `WITS-Deploy-Firmware-0.2.0-dev19.zip`: firmware for the T-QT Pro, Waveshare 7-inch and Waveshare 1.47-inch (SHA-256 alongside).
- `WITS-Deploy-0.2.0-dev19-Linux-x86_64.tar.gz`: the Linux desktop app. Extract with `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev19-Linux-x86_64.tar.gz -C ~/Apps`, then run `INSTALL-LAUNCHER.sh` from the extracted folder.
- `release-manifest.json` and `release-manifest.json.sig`: the signed manifest the app checks.
- Windows: run the app from source for now; see the README.

Not yet verified on hardware: Windows, interrupted Bluetooth updates, and USB storage on the Waveshare 7-inch.
