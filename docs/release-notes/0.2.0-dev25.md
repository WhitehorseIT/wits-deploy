**Test build.** A pre-release for hardware testing, not a stable release.

## What's new
- **Check for updates…** in the app. It looks for the newest signed release, the newest firmware and, with **Include development builds** ticked, the newest signed snapshot of the latest changes. On the packaged Linux build it hands over to **Update app…**; on a run-from-source install started with `WINDOWS-START.cmd` it downloads, verifies and installs the update, then restarts the app, with an automatic rollback if the new version fails to start.
- **Windows.** Pairing now happens inside the app (it answers Windows' PIN request itself), and a new **Remove** button forgets a board and removes its pairing from Windows' Bluetooth list too. A single launcher, `WINDOWS-START.cmd`, checks Python and the app's packages, installs what is missing and starts the app. Dead Bluetooth links are noticed within about 15 seconds, the operating system's connection is released when a link is lost, and a board that Windows is already linked to is reconnected directly.
- **Logs.** **Copy log** and **Save logs…** (one ZIP with the events, debug logs, crash traces and system details) under the board list, and **Copy output** and **Save output…** under the USB flash window.
- **Hide text** now shows one bullet per character instead of a blank box.
- **USB flash:** a board without the WITS flash layout (a new or blank one) now gets a clear message, and the dialog selects **Install blank board / factory recovery** for you.
- The window title shows the exact build, for example `0.2.0-dev25 (build ea2305d)`. Board-state badges no longer overprint their text on Windows. After an update the Linux app rebuilds KDE's menu cache in full.
- Firmware is unchanged: the app bundles 1.0.0-rc1.

## Updating
From 0.2.0-dev22 or newer the Linux app updates itself: use **Update app to 0.2.0-dev25…**. Apps older than dev22 cannot read this release's manifest (it lists a new file); install it manually: `mkdir -p ~/Apps && tar xzf WITS-Deploy-0.2.0-dev25-Linux-x86_64.tar.gz -C ~/Apps`, then run `INSTALL-LAUNCHER.sh` from the extracted folder. Windows runs from source: see the README.
